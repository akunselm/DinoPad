DINO PAD — UNITY 6 SOURCE PROJECT

This GitHub repository contains a complete Unity source project inside:
  DinoPad_Unity_Project - Copy/

It is NOT a .unitypackage or a pre-built executable.

KEYBOARD-ONLY QUICK START
1) Clone/download this GitHub repository and extract it if necessary.
2) Open Unity Hub > Add project from disk.
3) Select the inner DinoPad_Unity_Project - Copy folder (contains Assets, Packages, ProjectSettings).
4) Open in a compatible Unity 6 Editor. Stored editor version: 6000.6.6f1.
5) Open Assets/DinoPadGame/Scenes/DinoPadGame.unity.
6) Select the Dino Pad Game object. If using no Arduino, uncheck Connect On Start in the Dino Pad Uno Serial component.
7) Press Play. Use Space/W/Up to jump; S/Down to duck. Mouse/touch pads work too.

ARDUINO PAD QUICK START
1) Wire a normally-open Jump switch between Arduino D2 and GND.
2) Wire a normally-open Duck switch between Arduino D3 and GND.
3) Upload Assets/DinoPadGame/Arduino/DinoPad_Uno.ino using Arduino IDE 2.
4) Set Unity Player > Other Settings > API Compatibility Level to .NET Framework for desktop serial support.
5) Set Dino Pad Uno Serial > Port Name to the actual port. AUTO only works with exactly one serial port. Baud Rate: 115200.
6) Close the Arduino IDE Serial Monitor/Plotter before pressing Play in Unity.

SERIAL PROTOCOL
S,0,0 = neither pad pressed
S,1,0 = Jump pressed
S,0,1 = Duck pressed
S,1,1 = both pressed

The game retains a history of the last N button presses (default 10).
The winning score starts at 500 unless a different goal has been saved.
